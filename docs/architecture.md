# PyGiga Architecture

PyGiga is composed of several layers:

- `agents` – cognitive agent classes that implement perception, memory, reasoning, planning, action, and evaluation.
- `action` – concrete action modules for executing commands, API requests, browser actions, and more.
- `communication` – chat and prompt management for agent communication.
- `knowledge` – document and retrieval stores for knowledge management.
- `memory` – multiple memory systems for storing and recalling data.
- `models` – model loader and backend wrapper modules.
- `perception`, `reasoning`, `planning`, `learning` – domain-specific capabilities for the agent workflow.
