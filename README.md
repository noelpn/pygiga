# PyGiga

PyGiga is a modular AI agent framework for managing perception, memory, reasoning, planning, and action.

## Installation

```bash
pip install -e .
```

## Usage

Create an AGI instance and ask a prompt:

```python
from pygiga import AGI

agi = AGI()
response = agi.ask("Hello world")
print(response)
```
